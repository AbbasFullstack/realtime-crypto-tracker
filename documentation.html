Step-by-Step GitHub Pages Deployment Guide

1

Create a Free GitHub Account

GitHub Pages provides 100% free, fast, secure SSL hosting for static web templates. First, you need an active GitHub account.

  • Navigate to https://github.com in your web browser.
  • Click on the 'Sign up' button in the top right corner if you don't have an account.
  • Enter your email address, create a strong password, and choose a unique username.
  • Verify your account via the email confirmation link sent by GitHub.
  • Log into your new account to reach the GitHub Dashboard.
Pro Tip: GitHub Pages hosting is completely free for public repositories and automatically provides HTTPS (SSL certificate).
2

Create a New Repository

A repository (repo) is where all your web template HTML, CSS, JavaScript, and image files will be stored safely.

  • On your GitHub Dashboard, click the green 'New' button or the '+' icon in the header.
  • In the 'Repository name' box, type a clean name (e.g. apex-web-template or your brand name).
  • Keep the repository visibility set to 'Public' (GitHub Pages free hosting requires a public repository).
  • Check the option 'Add a README file' (recommended to initialize the main branch).
  • Click the green 'Create repository' button at the bottom of the page.
Pro Tip: Avoid using spaces or special characters in repository names. Use hyphens like 'my-portfolio' or 'company-website'.
3

Upload Your Template Files

Now upload all the HTML, CSS, JS, and image files from your downloaded template package directly into your repository.

  • Open the downloaded template zip file on your computer and open the 'template' folder.
  • In your GitHub repository web page, click on 'Add file' -> 'Upload files'.
  • Drag and drop ALL files and subfolders (index.html, assets/, etc.) directly into the GitHub dropzone box.
  • Wait for the upload progress bar to finish listing all your uploaded files.
  • Scroll down to 'Commit changes', enter a commit message like 'Initial template upload', and click 'Commit changes'.
Pro Tip: CRITICAL: Make sure 'index.html' is located directly in the root directory of your repository, NOT nested inside a sub-subfolder!
4

Navigate to Repository Settings -> Pages

Configure GitHub Pages to build and host your site directly from your repository files.

  • Inside your repository page on GitHub, click on the 'Settings' tab in the top navigation menu bar.
  • In the left sidebar menu under the 'Code and automation' section, click on 'Pages'.
  • You will see the 'GitHub Pages' setup page with 'Build and deployment' settings.
Pro Tip: If you don't see the Settings tab, ensure you are logged into the GitHub account that owns the repository.
5

Select Main Branch & Save Settings

Tell GitHub Pages which branch and folder to serve as the live public website.

  • Under 'Build and deployment', make sure Source is set to 'Deploy from a branch'.
  • Under 'Branch', click the dropdown currently showing 'None' and select 'main' (or 'master').
  • Keep the folder dropdown selector set to '/ (root)'.
  • Click the blue 'Save' button right next to the branch dropdown.
  • GitHub will now trigger an automated deployment action.
Pro Tip: Wait approximately 60 to 90 seconds for GitHub to process and build your live webpage for the first time.
6

Get Your Live Website URL!

Congratulations! Your website is published and accessible to anyone on the internet.

  • Refresh the Settings -> Pages page after 1 minute.
  • You will see a green success banner with a checkmark stating: 'Your site is live at https://yourusername.github.io/repo-name/'.
  • Click the 'Visit site' button or open the link in a new tab to see your template live!
  • (Optional) You can also connect a custom domain name (e.g. www.yourbrand.com) in the 'Custom domain' field below.
Pro Tip: If you update any HTML or CSS files in the future and commit changes, GitHub Pages updates your live site automatically within 1 minute!

Troubleshooting & FAQ

Q: Why are my images or styles broken after publishing on GitHub Pages?

This usually happens if relative paths in your HTML use leading slashes (e.g. '/assets/images/logo.png' instead of './assets/images/logo.png' or 'assets/images/logo.png'). GitHub Pages repositories run under a sub-folder path (username.github.io/repo-name/). Always use relative paths without a leading slash.

Q: Can I host this template on cPanel, Netlify, or Vercel instead of GitHub Pages?

Yes! This web template is 100% standard static HTML5, CSS3, and JavaScript. You can upload the contents of the 'template/' folder to any web server (cPanel public_html, Netlify, Vercel, Hostinger, GoDaddy, AWS S3) via FTP or web upload.

Q: How do I change the website logo and favicon?

Open index.html in any code editor (VS Code, Notepad++, Sublime Text). Search for ``.

Q: How do I change the template primary colors?

Open `assets/css/style.css`. At the top of the file, you will find CSS Custom Properties inside `:root`. Simply edit `--primary-color`, `--accent-color`, and `--bg-accent` hex values. You can also use the Live Color Customizer tool inside this documentation!

Q: How do I receive real emails from the contact form?

The contact form includes clean integration for Formspree / Web3Forms. Simply sign up for a free account on Formspree.io or Web3Forms.com, get your endpoint key, and replace `action="https://formspree.io/f/YOUR_FORM_ID"` inside `contact.html`.
