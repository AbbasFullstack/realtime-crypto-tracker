##  Features

- 🔄 **Real-Time Updates** - Live prices from CoinGecko API
- 💰 **Top 10 Cryptocurrencies** - Bitcoin, Ethereum, BNB, and more
- 📊 **Market Data** - Current price, market cap, volume
- 🎨 **Modern UI** - Built with Tailwind CSS & Next.js
- 📱 **Responsive Design** - Works on all devices
-  **Fast Performance** - Optimized with Next.js App Router
- 🔌 **API Routes** - Server-side API integration

## 📦 Installation

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Clone the Repository
```bash
git clone https://github.com/AbbasFullstack/realtime-crypto-tracker.git
cd realtime-crypto-tracker/frontend
```

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
